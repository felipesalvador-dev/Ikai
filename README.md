# 🌱 Ikai — Website Institucional

O **Ikai** é um projeto que propõe uma nova forma de consumir conteúdos digitais: com mais intenção, autonomia e controle.

Em um cenário no qual as plataformas digitais frequentemente utilizam mecanismos de recomendação e consumo contínuo, o Ikai busca colocar a pessoa usuária no centro da experiência, permitindo que ela escolha o que deseja consumir e estabeleça seus próprios limites.

Este repositório contém o **website institucional do Ikai**, desenvolvido para apresentar a proposta, seus princípios e diferenciais.

## 🎯 Objetivo do projeto

Apresentar o Ikai ao público, comunicar sua proposta de valor e demonstrar como o projeto pretende oferecer uma experiência digital mais consciente.

## 💡 Sobre o Ikai

O Ikai tem como princípio fundamental permitir que a pessoa usuária tenha autonomia sobre sua experiência digital.

Entre os conceitos que orientam o projeto estão:

- **Consumo consciente:** escolha intencional dos conteúdos que deseja visualizar.
- **Personalização manual:** controle sobre temas, categorias e formatos de conteúdo.
- **Sessões limitadas:** definição de limites de tempo e quantidade de conteúdos.
- **Feed finito:** navegação sem rolagem infinita ou reprodução automática.
- **Privacidade:** transparência e respeito aos dados pessoais.
- **Interações conscientes:** recursos sociais que respeitam as preferências individuais.

## 🖥️ Sobre o website

O website foi desenvolvido para apresentar a identidade e os conceitos do Ikai, incluindo:

- Apresentação da proposta do projeto.
- Explicação sobre o funcionamento do Ikai.
- Destaque para os principais diferenciais.
- Apresentação dos princípios de privacidade.
- Divulgação da identidade visual e dos valores do projeto.

## ⚙️ Executando o projeto localmente

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Git instalado.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd NOME_DO_REPOSITORIO
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o ambiente de desenvolvimento

```bash
npm run dev
```

Após executar o comando, o Vite disponibilizará um endereço local no terminal, geralmente:

```text
http://localhost:5173
```

### 5. Gere a versão de produção

```bash
npm run build
```

Para visualizar localmente a versão gerada:

```bash
npm run preview
```

## 🔒 Privacidade e propósito

A proposta do Ikai é desenvolver uma experiência digital que respeite a autonomia da pessoa usuária.

O projeto busca evitar mecanismos de consumo contínuo e oferecer maior transparência sobre a experiência, priorizando escolhas conscientes em vez de estímulos para permanência prolongada.
